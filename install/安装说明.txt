==============================================================
              抖音可可助手  ·  安装说明
==============================================================

这是给抖店商家用的小工具。装一次就行，以后会自动更新，
不用每次换版本都重新装。

整个安装就四步，大约两分钟。


--------------------------------------------------------------
第一步：解压
--------------------------------------------------------------
把收到的压缩包解压出来（解压到桌面也可以）。

  · Windows 11  ：右键压缩包  →  「全部解压」
  · Windows 10  ：右键压缩包  →  「解压到当前文件夹」

解压后会看到一堆文件和文件夹，找到其中的
        【  !安装助手.bat  】
双击它。


--------------------------------------------------------------
第二步：等黑窗口跑完
--------------------------------------------------------------
双击后会弹出一个黑色的窗口，它会自动：

  · 把插件文件装到  C:\DY-COCO
  · 帮你打开这个文件夹
  · 把安装路径复制到剪贴板（下一步要用）

窗口里出现「安装完成」后，按任意键关掉它。

  ⚠️ 如果弹出「Windows 已保护你的电脑」：
        点【更多信息】→【仍要运行】

  ⚠️ 如果 360 等安全软件拦截：
        选择【允许本次操作】

  这两个提示是因为这个文件是个人作者做的、没有花钱买数字签名，
  属于正常现象，可以放心运行。不放心的话，右键用记事本打开
  这个 bat 文件，里面的每一行都是看得懂的复制命令。


--------------------------------------------------------------
第三步：装进浏览器
--------------------------------------------------------------
1. 打开你的浏览器（360极速 / 夸克 / Chrome / Edge 都可以）

2. 在浏览器最上面的地址栏里输入下面这行，然后按回车：

         chrome://extensions

   （如果用的是 Edge，输入 edge://extensions）

3. 在打开的页面里，找到右上角的【开发者模式】开关，把它打开
   （开关变蓝或变成"开"就是打开了）

4. 点左上角的【加载已解压的扩展程序】

5. 会弹出让你选择文件夹的窗口。
   这时按一下  Ctrl + V  （粘贴），再按回车。

   路径已经在剪贴板里了，不用自己一层层去找。

6. 确定。


--------------------------------------------------------------
第四步：检查有没有装好
--------------------------------------------------------------
打开抖店后台的商品列表页面，看两个地方：

  · 页面左下角出现绿色小条「DY-COCO」       → 成功
  · 每个商品那一行右边出现【清空库存】按钮    → 成功

如果没看到，在页面上按一下 F5 刷新就可以了。


==============================================================
                三条红线（千万别做）
==============================================================

1. 不要删除  C:\DY-COCO  这个文件夹
   —— 删了插件就失效了

2. 不要移动它、不要给它改名
   —— 移动或改名等于重新安装，之前的设置会全部丢掉

3. 不要换一个路径重新装一遍
   —— 换路径浏览器会把它当成两个不同的插件，
      页面上可能出现两个「清空库存」按钮，很容易误点


==============================================================
                以后怎么更新？
==============================================================

不用管，插件会自己检查新版本，你点两下就更新好了。

  点浏览器工具栏上的插件图标
      → 弹窗最下面会显示【安装更新】
      → 点它 → 弹出确认框 → 点【确认】

首次更新时，会让你选一次文件夹（就是选 C:\DY-COCO）。
另外，每次重启浏览器之后第一次更新，可能要再点一次
【授权写入】，这是浏览器的安全规定，点一下就好。


==============================================================
                装第二台电脑 / 装给员工
==============================================================

每台电脑都要按上面四步装一次，插件本身不能复制粘贴。


==============================================================
                遇到问题怎么办
==============================================================

【按钮没出现】
  ① 确认自己打开的是「商品列表」页面
  ② 在页面上按 F5 刷新
  ③ 打开 chrome://extensions ，确认：
       - 插件卡片右边的开关是开着的
       - 页面右上角「开发者模式」还是开着的
        （关掉开发者模式不会卸载插件，但插件会停止工作，
          这是最容易忽略的一点）

【双击 bat 窗口一闪就没了】
  说明被系统拦住了。右键这个 bat 文件 → 【以管理员身份运行】。

【插件页面显示「已停用」或者红色报错】
  说明文件没有复制完整。重新解压一次，再双击一次安装助手。

【我装了新版，页面上却多出一个按钮】
  说明电脑上有两份插件。打开 chrome://extensions ，
  把多余的那一张卡片点【移除】删掉，只留一个。

【之前装过、现在想换成这个版本】
  先去 chrome://extensions 把旧的卡片【移除】，
  再按上面四步重新装一次。
