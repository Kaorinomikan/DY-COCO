# 可可助手（DY-COCO）

装在浏览器里的小工具，给做抖店、微信小店和直播中控的商家用：把那些必须一遍遍点的活，变成点一下。

当前版本 26.11.08.2。

## 它能帮你做什么

- 一键清空商品库存，不用逐个规格点。
- 批量处理渠道品，下架并删除。
- 输入序号直接滚到商品并高亮。
- 罗盘里一键复制货号，不用手抄。
- 粘贴链接或款号，自动加进小黄车。
- 到点自动重新讲解当前商品。
- 小黄车定时刷新，一开播就自己停。
- 超级福袋到点播报参与人数。

## 怎么装

1. 解压收到的压缩包。
2. 双击 `!安装助手.bat`，它会装到 `C:\DY-COCO`。
3. 打开浏览器的扩展管理页，开启「开发者模式」，点「加载已解压的扩展程序」，选 `C:\DY-COCO`。
4. 打开抖店后台，左下角出现 `DY-COCO` 就是装好了。

## 用之前要知道

- 清库存、下架删除、加车、讲解，这些会**真的改动你店铺的数据**，而且清掉的库存退不回来。动手前看清对象。
- 只在这个浏览器里生效，换浏览器要重新装一遍。

每个开关具体做什么、自动刷新的灯色怎么读、怎么更新和回退、出问题怎么查，都在 [使用手册.md](使用手册.md)。
