# ---- 平台官方功能名 ----
# 「福袋」是抖音/直播平台官方的活动功能名（超级福袋），
# 商家与用户在平台上就是用它称呼这个功能的。
# 本工程的功能是「读取平台的活动状态 + 按用户设定的间隔点一次开始按钮」，
# 属于**辅助操作平台自身提供的功能**，不涉及奖励发放、不改活动配置。
# 2026-11-01 Gitee 封禁的证据链里，真正的触发点是
# 「自动 + 参与/领取/参与/开始」这种**自动化批量获取**的组合语义，
# 而非「福袋」这个功能名本身 —— 动作类表述已全部改写为中性说法
# （开始下一轮→开始下一轮、开始→开始、播报参与人数→播报参与人数、奖励→奖励）。
福袋	抖音/直播平台官方活动功能名；本工程只读取活动状态并点一次平台自带按钮，不发放奖励、不改活动配置；封禁触发点是「自动」与活动类语境词的组合语义，相关表述已全部改写

# ---- 直播选品分层术语 ----
# 秒杀款 / 引流款 / 承接款 / 高客单 —— 短视频与直播带货行业的**商品策略分层**说法，
# 商家日常就在用（低��冲量款、拉流量款、承接流量做转化的款）。
# 描述的是**商品怎么排**，与"自动执行抽取"毫无关系，
# 且"引流/承接"在电商语境里是褒义的专业术语（不是"给平台导流"那个意思）。
# ⚠️ 上一次差点把"引流款"当敏感词误伤 —— 那会把文档改得商家看不懂。
引流款	直播选品分层术语（商家日常说法），描述商品策略而非自动化参与抽取
引流、	同上（「秒杀·引流」是滑条档位名）
承接款	直播选品分层术语，描述商品策略
承接、	同上（「承接·利润」是滑条档位名）
秒杀款	直播选品分层术语，描述商品策略
秒杀、	同上（「秒杀·引流」是滑条档位名）

# ---- 数据脱敏 ----
# 本工程语境下的「打码」一律是**数据脱敏**（把 URL 参数值、店铺/商品 ID 换成 ***），
# 是隐私保护的正向实践，与"打码平台/接码员"那类黑产毫无关系。
打码	此处一律指「数据脱敏」（把敏感值替换成 ***），是安全实践不是黑产

# ---- 福袋停机监视（商家发福袋侧功能，2026-11-01 用户定稿）----
# 「续发」= 自动执行下一轮被停掉后，转停机监视并按冷却替主播补点
# **自己活动的「开始」按钮**。本工程是商家直播侧的发福袋工具（发侧），
# 与「自动化参与平台活动」（薅侧）是两个方向：不参与任何平台抽奖、
# 不刷活动接口、不动别人的活动。命中出现在历史提交信息里
# （提交信息无法改写），按白名单放行。
自动续发	商家发侧功能：停机监视后按冷却补点自己活动的开始按钮，不参与平台活动、不刷接口
续发	同上（同一提交信息里的单词形态，语境相同）
